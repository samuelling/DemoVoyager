HOW A SEED BECOMES A DEMO

    
    
      
  1. One 32-bit seed is hashed into three sub-seeds for names, music and visuals, so each generator is independent of the others.
    2. 
      
  2. Music: a mode weighted toward minor, a key and tempo, two chord progressions, then drum, bass and arpeggio templates. Seven 8-bit samples are synthesized from formulas.
    3. 
      
  3. Melody: one-bar motifs get rhythms from a metric-weight profile and contours from a step-biased random walk. Strong beats snap to chord tones, phrases run AABA-style to a cadence on the root, and the last chorus can modulate up.
    4. 
      
  4. Visuals: each pattern draws an effect from eleven families with randomized parameters. Every palette comes from one cosine-palette family, so the whole demo shares a look.
    5. 
      
  5. Sync: the effects read the tracker rows as they play, so kicks, snares, bass and lead notes drive them, and scenes cut on pattern boundaries. In Endless mode the next seed is hashed from the current one, so the stream of demos is deterministic too.
